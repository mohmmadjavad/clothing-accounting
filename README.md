# 🏭 نرم‌افزار مدیریت تولید پوشاک

<div dir="rtl">

نرم‌افزار حسابداری و انبارداری تخصصی برای کسب‌وکارهای تولید پوشاک، طراحی‌شده با Python و PyQt6.

## 📸 ویژگی‌ها

- **داشبورد مدیریتی** — آمار لحظه‌ای فروش، مشتریان، سفارشات، و هشدار کم‌موجودی
- **مدیریت انبار** — ثبت کالا با تنوع رنگ و سایز، بارکد، و هشدار حداقل موجودی
- **مشتریان** — دفترچه مشتریان با حساب بدهکاری و بستانکاری
- **سفارشات / فاکتور** — صدور فاکتور با خروجی PDF فارسی
- **حسابداری** — ثبت دریافت و پرداخت، تسویه حساب، گزارش مالی مشتریان
- **دفتر برش** — ثبت عملیات برش پارچه با جزئیات رنگ و وزن
- **📈 گزارش‌ها (جدید)** — فروش ماهانه، محصولات برتر، مشتریان برتر، گزارش انبار با خروجی Excel
- **تنظیمات** — اطلاعات برند، تم روشن/تاریک، پشتیبان‌گیری خودکار

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.10 یا بالاتر
- ویندوز 10/11

### نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### اجرا

```bash
python main.py
```

```
clothing_erp/

│   ├── styles.py            # استایل‌های گلوبال
│   └── pages/
│       ├── dashboard.py     # داشبورد
│       ├── inventory.py     # انبار
│       ├── customers.py     # مشتریان
│       ├── orders.py        # سفارشات
│       ├── accounting.py    # حسابداری
│       ├── cutting.py       # دفتر برش
│       ├── reports.py       # گزارش‌ها (جدید)
│       └── settings.py      # تنظیمات

    ├── pdf_generator.py     # تولید فاکتور PDF

```

## 🛠️ تکنولوژی‌ها

| ابزار | کاربرد |
|-------|--------|
| PyQt6 | رابط کاربری گرافیکی |
| SQLite | پایگاه داده محلی |
| ReportLab | تولید PDF |
| jdatetime | تاریخ شمسی |
| openpyxl | خروجی Excel |
| arabic-reshaper + python-bidi | نمایش صحیح فارسی در PDF |

## 💾 پشتیبان‌گیری

برنامه هر ۷ روز یادآوری پشتیبان‌گیری می‌کند. فایل‌های بکاپ در مسیر تنظیم‌شده (پیش‌فرض `D:\ClothingERP_Backups`) ذخیره می‌شوند. فقط ۳ نسخه آخر نگهداری می‌شود.

## 🔧 تغییرات نسخه v2.2 (پچ کسب‌وکار)

### باگ‌های رفع‌شده
- **شماره فاکتور تکراری** — روش تولید اصلاح شد (از `MAX` به‌جای `COUNT` استفاده می‌شود)
- **تراکنش تسویه حساب** — منطق `debt/credit` اصلاح شد (آپدیت صحیح موجودی مشتری)
- **Rollback در خطاها** — تمام عملیات حیاتی اکنون در صورت خطا بازگشت می‌خورند
- **اعتبارسنجی موبایل** — فرمت صحیح موبایل (۱۱ رقم با ۰۹) بررسی می‌شود
- **خطای تکرار کد مشتری** — پیام خطای واضح‌تر نمایش داده می‌شود

### بهبودها
- **ایندکس‌گذاری دیتابیس** — ایندکس روی ستون‌های پرکاربرد برای سرعت بیشتر
- **بکاپ** — حداکثر بکاپ از ۳ به ۱۰ افزایش یافت
- **بازیابی از بکاپ** — دکمه Restore در صفحه تنظیمات اضافه شد
- **متدهای جدید دیتابیس** — `get_financial_summary()` و `search_orders()` اضافه شدند
- **به‌روزرسانی وضعیت پرداخت** — بعد از ثبت فاکتور بررسی می‌شود
